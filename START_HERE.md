Tap **+** button\n2. Fill in title (required)\n3. Add category, priority, deadline (optional)\n4. Add sub-tasks if needed\n5. Tap **Save**\n\n### Search for a Task\n1. Tap **search icon** in AppBar\n2. Type task name or description\n3. Results filter in real-time\n4. Tap **clear** to reset\n\n### Mark Task Complete\n1. Tap **checkbox** on task\n2. Task moves to \"Completed\" screen\n3. Reminder automatically cancelled\n\n### Change Theme\n1. Tap **theme icon** in AppBar\n2. Choose: Terang (Light) / Gelap (Dark) / Ikut sistem (System)\n3. Theme saves automatically\n\n### Sort Tasks\n1. Tap **sort icon** in AppBar\n2. Choose: Manual / Deadline / Prioritas / Nama\n3. Sort preference saves automatically\n\n---\n\n## ✅ Project Status\n\n```\n✅ Code Quality\n   ├─ flutter analyze: No issues\n   ├─ flutter test: 47/47 passing\n   └─ Build: Success (51 MB)\n\n✅ Features\n   ├─ Core: Complete\n   ├─ Search: Complete (NEW)\n   ├─ Notifications: Complete\n   └─ UI/UX: Complete\n\n✅ Documentation\n   ├─ Installation: Complete\n   ├─ Testing: Complete\n   ├─ Development: Complete\n   └─ Deployment: Complete\n\n🚀 Status: PRODUCTION READY\n```\n\n---\n\n## 📊 Quick Stats\n\n| Metric | Value |\n|--------|-------|\n| Tests Passing | 47/47 (100%) ✅ |\n| Code Issues | 0 ✅ |\n| APK Size | 51 MB |\n| Min Android | 5.0 (API 21) |\n| Features | 25+ |\n| Documentation | 7 guides |\n\n---\n\n## 🆘 Need Help?\n\n### Installation Issues\n→ See [INSTALL_GUIDE.md](INSTALL_GUIDE.md) → Troubleshooting\n\n### Feature Questions\n→ See [TESTING_CHECKLIST.md](TESTING_CHECKLIST.md)\n\n### Development Questions\n→ See [QUICK_REFERENCE.md](QUICK_REFERENCE.md) → Troubleshooting\n\n### General Questions\n→ See [DOCS_INDEX.md](DOCS_INDEX.md)\n\n---\n\n## 🎓 Learning Path\n\n### Beginner (Just want to use the app)\n1.
