HOW TO INSTALL ON PHONE
================================================================================

Option 1: Via USB (Recommended)
1. Connect phone via USB
2. Enable USB Debugging on phone
3. Run: flutter install
   OR: adb install build/app/outputs/flutter-apk/app-release.apk

Option 2: Via File Transfer
1. Copy APK to phone's Download folder
2. Open file manager on phone
3. Tap APK file to install

Option 3: Via Email/Cloud
1. Upload APK to Google Drive / Email
2. Download on phone
3. Tap to install

See INSTALL_GUIDE.md for detailed instructions.
